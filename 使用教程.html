家长留言板 v2 — 使用教程

一、系统架构（新版）

家长端微信扫码 → GitHub Pages网页 → 选班级 → 发留言
教室端一体机双击小组件 → 屏幕右下角弹出原生窗口 → 滚动显示当日留言 → 每5秒刷新
管理端老师电脑打开 留言管理后台.html → 管理班级和留言
后端腾讯云SCF（广州）→ 微信云开发数据库
新版无需本地服务器，小组件基于 Windows 内置 WebView2 运行，无需额外安装运行环境。

二、教室一体机部署（每班一个）

小组件是 Windows 原生窗口（PowerShell + WebView2），不是浏览器页面。深色圆角悬浮窗，置于桌面层级，不遮挡课件，无任务栏图标。

方式A：便携使用（无需安装）

  1. 解压 各班教室小组件-v2.zip
  2. 找到本班文件夹（如"五（1）班"），整个文件夹放到一体机桌面或任意位置
  3. 进入文件夹，双击 launch-widget.vbs
  4. 屏幕右下角弹出小组件，每5秒自动刷新当日留言

不写C盘，不写注册表，删文件夹即卸载。适合临时使用或测试。

方式B：安装到系统（推荐）

  1. 进入班级文件夹，双击 install.bat
  2. 自动将文件复制到 %USERPROFILE%\ParentBoard\，创建桌面快捷方式，设置开机自启动
  3. 桌面双击"家长留言板"即可启动

修改班级

  1. 先在管理后台"班级管理"中添加新班级（如还没有的话）
  2. 打开小组件所在文件夹中的 config.json
  3. 修改 "class_code" 为新的班级名称，保存
  4. 重新启动小组件即可
便携版：config.json 在班级文件夹内。安装版：config.json 在 C:\Users\用户名\ParentBoard\ 下。改班级前务必先在管理后台添加好该班级。

卸载

  • 便携版：直接删除班级文件夹即可，无残留
  • 安装版：双击 C:\Users\用户名\ParentBoard\uninstall.bat，自动清理快捷方式、开机自启和所有文件

三、家长如何使用

入口

微信扫码打开：

网址：https://wl-123888.github.io/liuyanban/

操作步骤

  1. 选择孩子所在的班级（如"五（1）班"）
  2. 输入留言内容（限200字），点击"发送到教室大屏"
  3. 发送成功后教室大屏几秒内就会显示
  4. 在"我的留言"区域只能看到自己发的留言，看不到其他家长的
  5. 点击"切换班级"可更换班级

隐私保护

  • 每位家长自动分配匿名ID，存储在手机浏览器中
  • 家长只能看到自己的留言，看不到别人的
  • 数据存储于腾讯云微信云开发（境内服务器）

四、远程管理后台（老师用）

入口

用桌面上的 留言管理后台.html 文件，浏览器直接打开即可。

两个标签页：

  • 留言管理 — 选择班级，查看/删除今日留言
  • 班级管理 — 添加/删除班级，家长端立即生效

添加班级

  1. 切换到"班级管理"标签
  2. 输入班级名称（如"五（1）班"），点击"添加"
  3. 刷新后家长端即可看到新班级

删除留言

  1. 切换到"留言管理"标签
  2. 选择班级，点击"刷新"
  3. 点击留言右侧的"删除"按钮
注意：删除班级不会影响已存在的留言记录。教室大屏只显示当日留言。

五、常见问题

Q：家长扫码后看不到自己班？

先在管理后台"班级管理"中添加该班级。添加后刷新页面即可看到。

Q：家长发了留言，教室大屏不显示？

大屏每5秒自动刷新，稍等几秒即可。如果超过30秒不显示，检查一体机是否能正常上网。

Q：教室大屏显示的不是自己班的留言？

检查打开的是否为本班的HTML文件（文件名上标了班级）。每个班有独立的HTML文件。

Q：怎么查看之前的留言？

教室大屏只显示当日留言，方便家长接送通知。管理后台也只能看到今日留言。

Q：怎么生成家长扫码用的二维码？

使用教程中已内置二维码（见上方"家长如何使用"入口处），直接截图打印即可。如需重新生成，用草料二维码等工具输入网址 https://wl-123888.github.io/liuyanban/。

Q：换了一体机或者重装系统了怎么办？

把对应班级的HTML文件重新复制过去，双击打开即可，无需安装任何东西。

Q：留言管理后台打不开？

确认 留言管理后台.html 文件在桌面上，用浏览器直接打开。不需要联网到特定服务器，能上网就能用。
